1点をタップして拾う

ほしい点のあたりをさわると、線の端・角・円の中心・交点・記号に吸い付きます。点名と種類（設計点＝杭を打つ点／既知点＝杭ナビの位置決めに使う点）を入れて「保存」。

事務所でやること(手順)

    足す点ファイルは、SIMA なら X=北・Y=東・m、CSV なら「くわしい設定」の向きと単位で読みます。KBM・BM・KS・T などで始まる点名は既知点にします（一覧で入れ替えられます）。

    1線をタップ → 逃げ墨の点

    逃がしたい線をタップしてください。▲が線の始まりで、左右は始まりから見た向きです。

    1点をつないで測る

    測りたい点を順にタップ（吸い付きます。吸い付かない所はタップした所）。2 点で距離・方向角、3 点以上で合計と面積。

    1杭ナビを置く場所と既知点2点

    杭ナビは既知点2点を測って自分の位置を出します（器械点は杭の上でなくてよい）。図で置く場所の目安と、2点の選び方がよいかを確かめます。

    距離は目安です。器械の仕様・天気・プリズムで変わるので、現場に合わせて直してください。

          くるくる回し太郎 ― 使い方
          
        
          杭ナビ（LN-150 ＋ TopLayout）で杭を打つための段取りアプリです。図面（DXF・図脳RAPID）か点ファイル（CSV・SIMA）を開いて、杭を打つ点を作り、杭ナビを置く場所と既知点2点を決め、TopLayout 用のファイルを書き出し、打った杭を照らし合わせます。スマホのブラウザだけで動きます（オフライン可）。杭ナビ本体を動かすのは TopLayout です。
          
        
          画面
          
        
          ふだんは ① 据付 → ② 杭打ち → ③ 確認 の順に使います。杭を打つ点(座標値)を作る・直すときだけ ⚙ 座標値設定 を開きます。
          
        
            
          
          1. ⚙ 座標値設定 → 拾う（一発かまし太郎と同じ）… 点をタップ → 点名・種類（設計点／既知点）を入れて保存。点ファイルの点をまとめて入れることもできます。
            2. 
          
          2. ⚙ 座標値設定 → 逃げ墨（一撃逃墨太郎と同じ計算）… 線をタップ → 逃げ寸法・左右・間かくで逃げ墨の点 → 一覧に入れる。
            3. 
          
          3. ⚙ 座標値設定 → 寸法（脳みそバーンと同じ）… 点をつないで距離・方向角・面積。
            4. 
          
          4. ① 据付 … 図をタップして杭ナビを置く場所を決めると、既知点2点までの距離・2点の開き（30〜150° を目安）・届く設計点の数が出ます。「よい場所を探す」で候補を3つ出します（図の上だけで探すので、見通しは現場で確かめてください）。
            5. 
          
          5. ⚙ 座標値設定 → 一覧・書き出し … 点名（半角英数16文字）・重複・高さを確かめて、TopLayout 用の CSV・SIMA に書き出します。
            6. 
          
          6. ② 杭打ち … 次に打つ点を大きく出します(杭ナビからの距離・方向角、既知点1から右回りの角)。「打った」で印を付け、「次の点」でいまの点から近いまだの点へ。図の点をタップしても選べます。
            7. 
          
          7. ③ 確認 … TopLayout の出力（現場名_stk.csv など）を開いて、設計とのずれ・許容外・まだ打っていない点を出します。
            8. 
        
          
        
          メニュー・操作盤(準備中)
          
        
          右上の「メニュー」は TopLayout のホームと同じ並び(現場・器械設置・放射観測・杭打ち・入力・出力・設定・点検)です。🎛 は杭ナビの操作盤です。杭ナビとのつなぎ方が分かったら、ここから杭ナビを動かせるようにする予定で、いまはボタンを押しても杭ナビには何も送りません。
          
        
          注意
          
        
            
          
          • 点名は半角英数（SIMA・杭ナビで全角が困ります）。同じ点名を杭ナビに入れ直すと上書きされず追加されます。
            • 
          
          • 拾った点・杭ナビの位置はこのスマホに覚えておきます（同じ図面を開き直すと戻ります）。
            • 
          
          • 図脳の図面に公共座標（座標の原点）が設定されていれば、公共座標（X=北・Y=東）で読みます。
