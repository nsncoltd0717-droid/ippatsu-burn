          🔗 杭ナビへのつなぎ方(Android)

          このアプリ(Android 版)は、中の中継が自動で動いています。Termux はいりません。

          Wi-Fi でつなぐ:スマホの Wi-Fi を杭ナビにつなぐ(「インターネットなし」と出たら「接続を維持」)→ 下のボタン。LIVE の映像も見られます。

          Bluetooth でつなぐ:はじめに Android の 設定 › Bluetooth で杭ナビとペアリング → 下のボタン →(初回だけ「付近のデバイス」を許可)→ 杭ナビを選ぶ。Wi-Fi は何でもかまいません。映像は出ません。

          どちらも TopLayout は閉じてください(杭ナビは1台としか話しません)。一度選べば、次からは上の「つなぐ」だけで同じつなぎ方になります(メニュー › 設定 › つなぎ方 でも変えられます)。

          LIVE の映像が出ないときは、LIVE を開いたあとに下のボタンで映像の記録を保存して送ってください。

          Termux なしで試す(Bluetooth・ためし) 1. Android の 設定 › Bluetooth で杭ナビとペアリング(TopLayout は閉じる)
          2. 下のボタン → 出てきた一覧から杭ナビを選ぶ
          映像(LIVE)は出ません。回す・サーチ・測る・ガイド光などが動くかを見てください。

          Wi-Fi でつなぐときは、ブラウザが杭ナビに直接つなげないので、スマホの中で「くるくる中継」を動かして間に立たせます。最初の1回だけ ①〜③ をします(③までは電波が要ります)。

          1. Termux を入れる:F-Droid から Termux を入れます(Google Play 版は古くて動きません)。
            F-Droid の Termux のページ
          2. Python を入れる:Termux を開いて、次を貼り付けて実行。
            pkg install -y python && termux-setup-storage
            (途中の「ファイルへのアクセス」は「許可」)
          3. 中継をスマホに置く:
            ダウンロードできないとき(どちらか)
            ア)Termux で次を実行(電波が要ります)
            イ)Termux で次を実行
            cat > ~/storage/downloads/kurukuru_relay.py
            → 下のボタンでコピー → Termux の画面を長押しして「Paste」→ CTRL を押しながら d(元の「$」に戻れば保存できています)

            LIVE の映像と、杭ナビのアドレスを自動でさがすのには中継 v3 が要ります。前の中継を入れた人も、もう一度ダウンロードして置きかえてください(同じ名前で保存されたら古い方を消す)。

          毎回(現場で)

          1. Termux で次を実行(「待っています」と出たらそのまま)。
            python ~/storage/downloads/kurukuru_relay.py
          2. スマホの Wi-Fi を杭ナビにつなぐ(「インターネットなし」と出たら「接続を維持」)。モバイルデータは切る(切らないと中継の通信がモバイルデータの方へ行ってしまうことがあります)。TopLayout は閉じる。
          3. くるくる回し太郎に戻って「🔗 つなぐ」。Chrome が「ローカル ネットワーク上のデバイスへのアクセス」をたずねたら「許可」。

          うまくいかないとき:Termux を開いたままにする(電池の最適化を「制限なし」に)/Wi-Fi が杭ナビになっているか/中継の画面に「杭ナビにつながりました」と出るか、を確かめてください。iPhone ではこのつなぎ方は使えません。

          くるくる回し太郎 ― 使い方
          
        
          杭ナビ（LN-1000i・LN-150 など ＋ TopLayout）で杭を打つための段取りアプリです。図面（DXF・図脳RAPID）か点ファイル（CSV・SIMA）を開いて、杭を打つ点を作り、杭ナビを置く場所と既知点2点を決め、TopLayout 用のファイルを書き出し、打った杭を照らし合わせます。スマホのブラウザだけで動きます（オフライン可）。杭ナビ本体を動かすのは TopLayout です。
          
        
          画面
          
        
          ふだんは ① 据付 → ② 杭打ち → ③ 確認 の順に使います。杭を打つ点(座標値)を作る・直すときだけ ⚙ 座標値設定 を開きます。
          
        
            
          
          1. ⚙ 座標値設定 → 拾う（一発かまし太郎と同じ）… 点をタップ → 点名・種類（設計点／既知点）を入れて保存。点ファイルの点をまとめて入れることもできます。
            2. 
          
          2. ⚙ 座標値設定 → 逃げ墨（一撃逃墨太郎と同じ計算）… 線をタップ → 逃げ寸法・左右・間かくで逃げ墨の点 → 一覧に入れる。
            3. 
          
          3. ⚙ 座標値設定 → 寸法（脳みそバーンと同じ）… 点をつないで距離・方向角・面積。
            4. 
          
          4. ① 据付 … 図をタップして杭ナビを置く場所を決めると、既知点2点までの距離・2点の開き（30〜150° を目安）・届く設計点の数が出ます。「よい場所を探す」で候補を3つ出します（図の上だけで探すので、見通しは現場で確かめてください）。
            5. 
          
          5. ⚙ 座標値設定 → 一覧・書き出し … 点名（半角英数16文字）・重複・高さを確かめて、TopLayout 用の CSV・SIMA に書き出します。
            6. 
          
          6. ② 杭打ち … 次に打つ点を大きく出します(杭ナビからの距離・方向角、既知点1から右回りの角)。「打った」で印を付け、「次の点」でいまの点から近いまだの点へ。図の点をタップしても選べます。
            7. 
          
          7. ③ 確認 … TopLayout の出力（現場名_stk.csv など）を開いて、設計とのずれ・許容外・まだ打っていない点を出します。
            8. 
        
          
        
          メニュー・操作盤(準備中)
          
        
          右上の「メニュー」は TopLayout のホームと同じ並び(現場・器械設置・放射観測・杭打ち・入力・出力・設定・点検)です。🎛 は杭ナビの操作盤です。杭ナビとのつなぎ方が分かったら、ここから杭ナビを動かせるようにする予定で、いまはボタンを押しても杭ナビには何も送りません。
          
        
          📹 LIVE(準備中)
          
        
          メニューの「LIVE」か 🎛 操作盤の「📹 LIVE」で開きます。LN-1000i のカメラ映像を見ながら、映像をタップしてその方へ杭ナビを回す(タッチドライブ)・回転サーチ(全周・±90°・±45°、右回り・左回り)・方位盤をタップしてその方位へ回す、ができるようにする画面です。LIVE の下にも、いつもの操作部(回す・サーチ・測定・追尾など)を置いています。いまは杭ナビとつながっていないので、針の動きは見本です。
          
        
          🔗 杭ナビにつなぐ(テスト版・Android)
          
        
          杭ナビと TopLayout のやりとりを読み解いて、くるくる回し太郎からも動かせるようにしました。ブラウザは杭ナビに直接つなげないので、スマホで「くるくる中継」(くるくる中継.py)を動かして間に立たせます。くわしい手順は 🎛 操作盤の下の「🔗 杭ナビへのつなぎ方(Android)」にあります(中継のダウンロード・コマンドのコピーもそこから)。◁▷ は押している間だけ回ります。点の方向へ回すには、器械設置で「🧭 向きを合わせる」(既知点1のプリズムを追尾して押す)をしてください。
          
        
          🏗 現場
          
        
          メニューの「現場」で現場を作ると、図面と座標データ(点・既知点・杭ナビの位置・打った杭)を現場ごとにこの端末へ自動で保存します。アプリを閉じても、別の図面を開いても点は消えません(現場を開いているときに図面を開くと、図面だけ入れ替わります)。現場を切り替えると、その現場の図面と点が開きます。「⬇ この現場を保存」で現場を丸ごと1つのファイル(kurukuru_〜.json)にしてダウンロードでき、「⬆ 保存した現場を読み込む」で別のスマホや PC にそのまま入れられます(バックアップにも)。ブラウザのデータを消すと端末の中の現場も消えるので、ときどきファイルに保存しておくと安心です。
          
        
          📋 座標リスト
          
        
          メニューの「座標リスト」か 🎛 操作盤・LIVE の「📋 座標リスト」で開きます。点名でさがし、設計点・既知点・まだ打っていない点・杭ナビから近い順で絞れます。点をタップすると、出す点にする・その方へ回す・既知点1/2にする・LIVE で見る、ができます。① 据付・器械設置の「📋 リストから選ぶ」から開くと、タップした点がそのまま後方交会の既知点になります。「⬇ CSV」「⬇ SIMA」で、いま表示している点(さがす・絞り込み・並びのとおり)をダウンロードできます。CSV は 点名,X,Y,H(TopLayout と同じ形)、SIMA は X=北・Y=東・m です。
