# 引継ぎメモ：脳みそバーン無敵CAD forWindows（一発かまし太郎入り）

2026-11-21 作成（依頼：しおりちゃん）

## 1. これは何か
- 脳みそバーン無敵CAD（nomiso.html v0.13.0）と 一発かまし太郎（kamashi.html v1.3.1）を、1つの Windows アプリにまとめたもの。
- インストール不要。zip を展開して `NomisoBurnCAD.exe` をダブルクリックで起動。
- 2本の切り替え：画面左上のボタン（「③ かまし太郎へ」「① 脳みそバーンへ」）、またはメニュー「アプリ」の Ctrl+1 / Ctrl+2。
- 現場の図面・座標（IndexedDB・localStorage）は2本で共通。データの置き場所は `%APPDATA%\脳みそバーン無敵CAD`。
- 書き出し（DXF・CSV・SIMA など）は「名前を付けて保存」の窓が出る（初期の場所は「ドキュメント」）。
- くるくる回し太郎は入っていない。くるくるへ渡す場面では「タブレットのアプリで開いてください」と案内だけ出す。
- 未署名なので、初回に Windows が「PC を保護しました」と出したら「詳細情報」→「実行」。

## 3. 作り（写真ペン太郎 forWindows と同じ方式）
- Electron 39.8.9 ＋ @electron/packager 20.3.0（win32 x64、asar）。exe のアイコン・版情報は resedit 3.1.1 ＋ png-to-ico 3.0.2 で書き換えるので、Linux でも wine なしで組める。言語ファイルは ja / en-US だけ残す。
- `windows/nomiso/` の中身
  - `package.json`：version を脳みそバーンの版に合わせる（今は 0.13.0）
  - `main.js`：`app://nomiso/` という独自スキームで app/ を配信（file:// だと DWG 用の libredwg(wasm) が読めないため）。単一起動、外のリンクは既定ブラウザ、nomiso.html と kamashi.html 以外へは移動しない、保存は「名前を付けて保存」、メニュー（アプリ切り替え・拡大縮小・全画面・開発者ツール）
  - `preload.js`：保存のファイル名を本体に知らせる口（`window.nomisoApp.noteDownload`）
  - `build.js`：組み立て一式（下の4つの手順）
  - `README.md`：短い説明
- build.js がリポジトリ直下の `nomiso.html`・`kamashi.html`・`vendor/libredwg` を `app/` に写すときに、次だけ手当てする（元の HTML はさわらない）
  1. 先頭に小さな script を差し込む：`a.download` の名前を本体へ知らせる（app:// の blob 保存は名前が落ちて「download」になるため）
  2. 題名に「forWindows」を付ける
  3. `sw.js` を登録しない
  4. ⌂（アプリを選ぶ画面へ）を、もう片方への切り替えボタンにする
  5. 「くるくる回し太郎を開きますか?」を案内だけにする
  - 手当ての場所が見つからないときは build.js がエラーで止まる（元の HTML の書き方が変わったら、build.js の該当文字列を直す）

## 4. 版を上げるとき（脳みそバーン・かまし太郎を直したあと）
1. main の nomiso.html / kamashi.html を最新にする（ふだんどおり make_apps.py で書き出してリポジトリへ）
2. `windows/nomiso/package.json` の version を脳みそバーンの版に変える
3. 組み立て
   ```
   cd windows/nomiso
   npm install
   node build.js
   ```
   → `dist/脳みそバーン無敵CADforWindows_v<版>.zip`
4. zip を共有フォルダと PC の置き場所へ。古い版の zip は消すか「旧版」へ
- 使う人は新しい zip を展開して古いフォルダと入れ替えるだけ。データは %APPDATA% にあるので消えない

## 5. 確かめたこと・まだのこと
- 確かめた（クラウドの Linux 上で同じ main.js を Electron で起動）：DXF を開いて表示、DWG 用 libredwg(wasm) の読み込み、IndexedDB・localStorage、2本の切り替え、保存の名前と「名前を付けて保存」窓、画面のエラーなし
- まだ：Windows 実機での起動確認、実際の DWG 図面での確認
- 自動更新はない（iPhone 版のように開くと新しくなる仕組みは無し）。版を上げたら zip を配り直す
