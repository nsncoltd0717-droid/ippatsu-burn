## これは何か

一発バーンの「写真ペン太郎」（リポジトリ直下の `pen.html`）を、Windows の窓で動くアプリにしたもの。
中身・使い方はスマホ版と同じで、写真に黒板や書き込みを入れ、ひな形Excelに貼って書き出す。

- 版：Windows 版の本体は 0.3.0（`package.json`）。中の写真ペン太郎は pen.html の版（いまは v0.2.0）。見出しに「写真ペン太郎 v0.2.0 forWindows 0.3.0」と両方出る
- 配り方：インストーラー `写真ペン太郎forWindows_Setup_v<版>.exe`
  - ダブルクリック → 入れる場所を選んで「インストール」。管理者権限は要らない（使う人ごとに入る。入れる場所は変えられる）
  - デスクトップとスタートメニューに「写真ペン太郎」ができる。消すときは Windows の「設定 → アプリ」から「写真ペン太郎」をアンインストール
  - 新しい版は、新しいインストーラーをそのまま実行すれば上書きされる
- 初回に「WindowsによってPCが保護されました」と出たら「詳細情報 → 実行」（署名していないため）
- インストールしない「フォルダ版」（zip を展開して `ShashinPenTaro.exe`）も組み立てのたびにできる。予備として使える

## 画面（パソコン用の2列）

- 左：工事写真の枠。ひな形と同じく1ページ3枚、写真の右に Excel に入る黒板の行を出す（枠に入らない行は赤字で知らせる）。ページ送り・拡大縮小（Ctrl＋ホイールも可）。
  - 写真をダブルクリック（または「✎ 編集」）で、別の窓に編集画面が開く（0.4.0 から）。一覧の窓はそのまま見ていられ、編集の窓で直した黒板や書き込みはすぐ一覧に映る。編集の窓が開いているときに別の写真をダブルクリックすると、同じ編集の窓がその写真に替わる。「✕ 閉じる」で保存して閉じる。
  - 窓どうしは BroadcastChannel「pen-sync」で知らせ合い、IndexedDB から読み直す（desktop.js の syncFromDb）。0.3.0 の本体（main.js が別の窓を許さない）では、今まで通り同じ窓の中で編集する。
  - 写真をドラッグして並べ替え、🗑 で消す。
  - 「⚙ 初期設定」で元の設定画面（片面/両面・工事名・黒板の項目・ひな形）を出す。「Excelに書き出す」は今までと同じ。
- 右：元の写真。上に「📁 フォルダを足す」で足したフォルダ、下に「このパソコン」（ピクチャ・デスクトップ・ドキュメント・ダウンロード・各ドライブ）のツリー。フォルダを選ぶと写真の一覧が出る。
  - 写真を左の枠へドラッグすると、その位置に貼る（Ctrl/Shift で複数選んでまとめて）。ダブルクリックか「選んだ写真を足す」で最後に足す。エクスプローラーからのドラッグも可。
  - 貼った写真には「貼付済」の印が付く。
- 2列のしるし（`dk`・`dk-cfg`）は `<html>` に付ける。pen.html は画面を替えるとき `document.body.className` を丸ごと書き換えるので、body に付けると消える。
- 中身は `desktop.js` / `desktop.css`。pen.html の関数（addFiles・openItem・renderList・excelLines など）をそのまま使っているので、pen.html のそれらの名前を変えるときは desktop.js も合わせる。

## 現場ごとの写真帳（登録現場とのリンク）

- 一発バーンの「いまの現場」（Genba、IndexedDB「ippatsu-genba」）ごとに、写真と初期設定（工事名・黒板の項目・片面/両面など）を分けて持つ。ひな形Excelは全現場で共通。
- 左上の「🏗 現場名 ▾」で現場を選ぶ・新しい現場を作る。見出しの下の「🏗」バッジで切り替えても同じ。はじめての現場は写真が空で、工事名に現場名が入る。
- 仕組み：pen.html は写真を「sp-album」、設定を localStorage「sp.cfg」に1組だけ持つ。現場が替わったら、今の組を IndexedDB「pen-sites」に現場名で預け、替わった先の組を戻して読み直す（desktop.js の swapAlbum）。いまどの現場の組が入っているかは localStorage「pen.win.albumSite」。
- Windows 版には一発バーンのメニューが無いので、現場の名前を変える・消すはまだできない（消しても写真は「pen-sites」に残る）。

## 作り方（仕組み）

- Electron 39.8.9 を使ったアプリ。@electron/packager 20.3.0 で Windows 64bit 用のフォルダを組み立て、electron-builder 26.18.1（NSIS）でそのフォルダをインストーラーに包む。
- exe のアイコンと版情報は resedit 3.1.1 で書き換え。アイコンは `icon.ico`（icon-512.png から 16〜256 の大きさを入れて作ったもの）。
- `app://pen/` という自前の住所で `pen.html` を開く（file:// だと DWG 読み込み部品 vendor/libredwg が動かないため）。
- `pen.html` 自体はさわらない。Windows 版だけの手当ては `main.js` が pen.html を開くときに入れる（更新で取ってきた pen.html にも同じように入る）：
  - 見出しに「forWindows」を付ける
  - ホーム画面アプリ用の sw.js の登録を外す
  - 書き出しファイル名を本体に知らせる小さな script（app:// の blob 保存だと名前が「download」になってしまうため。preload.js の `penApp.noteDownload` と対）
  - `desktop.css` と `desktop.js` を差し込む（2列の画面・更新ボタン・「写し太郎の写真から」ボタンを隠す）
- Excel・画像の書き出しは「名前を付けて保存」の窓で保存先を選ぶ。前に選んだフォルダを覚える。保存後に「開く／フォルダを開く」を出す。

| ファイル | 役目 |
|---|---|
| `package.json` | 版・使う部品の版 |
| `main.js` | 窓・app:// の配信・pen.html への手当て・保存の窓・メニュー・フォルダを見る・アプリの更新 |
| `desktop.js` / `desktop.css` | パソコン用の2列の画面と「アプリの更新」ボタン |
| `preload.js` | 画面から本体へ頼む橋渡し（書き出し名・フォルダ・更新） |
| `build.js` | pen.html を写して手当て → フォルダ版を組み立て → exe のアイコン → zip → インストーラー |
| `icon.ico` | exe とインストーラーのアイコン |
| `README.md` | 組み立ての手短な説明 |

## 版を上げるとき（組み直し）

1. リポジトリ直下の `pen.html` を新しい版にする（一発バーンのアプリ版と同じもの）。
2. pen.html・desktop.js・desktop.css だけの変更なら、main へマージすれば各PCの「アプリの更新」で届く（インストーラーは作り直さなくてよい）。main.js・preload.js を変えたときは `windows/pen/package.json` の `version` を上げて、下の手順でインストーラーを作り直す。
3. Windows の PC で組み立て（インストーラーは Windows でしか作れない）：
   ```
   cd windows/pen
   npm install
   npm run build
   ```
   `dist\` に `写真ペン太郎forWindows_Setup_v<版>.exe`（インストーラー）と、フォルダ版 `写真ペン太郎forWindows_v<版>\` ができる（フォルダ版の zip は python3 があるときだけ）。
4. インストーラーを共有ドライブ `Claude(一撃墨太郎)\写真ペン太郎\` に置き、古い版のインストーラーは消す。
5. このメモの「作業記録」に1行足す。

手元で試すだけなら `npm start`。
